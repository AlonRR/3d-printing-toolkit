# print-chamber box — moved

their own repository on 4 Oct 2026, with their history. The box is now the **air-quality monitor**, in the
**air-quality-monitor** repository, and work on either happens there.

The rest of the chamber family stays here: the chamber-sensor notes,
[`docs/chamber-sensor.md`](../../docs/chamber-sensor.md), and the node in service,
[`firmware/chamber-c3.yaml`](../../firmware/chamber-c3.yaml).
