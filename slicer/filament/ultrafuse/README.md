# Ultrafuse (Forward AM)

## `Ultrafuse TPU-95A - Copy`

A user-modified copy of the **system** `Ultrafuse TPU-95A` preset. As with the printer preset, the
`- Copy` suffix is what PrusaSlicer names a user preset saved over a system one, so there is no user
preset of the plain name for it to duplicate — the original lives in the vendor bundle.

| | |
|---|---|
| Inherits | `Ultrafuse TPU-95A` (system) |
| Type | FLEX |
| Vendor | Forward AM |
| Keys | 85 |

**Not the same material as the Inslogic TPU presets** in `../inslogic/`, which are a different
vendor's TPU 95A and were derived from their own data sheet. Both are 95A flexibles; neither
profile's numbers transfer to the other spool.

**Status: inherited, not validated here.** This preset dates from May 2026 and no calibration print
against it is recorded in this repo. Treat its values as the vendor's starting point rather than as
something this lab has proven, and record any change with its reason — the convention the unbranded
PETG notes follow.

Versioned 23 Sep 2026; it had no master until then. Stored LF per `.gitattributes` while the live
copy is CRLF — compare with `diff --strip-trailing-cr`.
